## Aprendizados

### Aula 01 — Fundamentos de Git e Docker
- Criação e gerenciamento de repositório público no GitHub
- Workflow com branches de feature e merge para main
- Escrita de Dockerfile e execução de container
- Boas práticas de commits (Conventional Commits)

**Branch utilizada:** `feature/aula-01-app`

### Aula 02 — Docker Compose + IA como Copiloto
- Orquestração de múltiplos containers com Docker Compose
- Configuração de volumes nomeados, redes customizadas e healthchecks
- Uso de variáveis de ambiente via `.env`
- IA (Kiro) como copiloto para análise e geração de infraestrutura

**Branch utilizada:** `entregas/aula-02/6325109`

### Aula 03 — Terraform + IAM
- Provisionamento de infraestrutura na AWS com Terraform
- Configuração de providers, users, groups, roles e policies IAM
- Princípio do menor privilégio aplicado em políticas customizadas
- Uso de `terraform plan` e `terraform apply` com evidências
- Gerenciamento de state e `.gitignore` para arquivos sensíveis

**Branch utilizada:** `6325109/tf-03`
